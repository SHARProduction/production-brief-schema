# План версий кампании · 0.1.0

Матрица результатов по длительности, форматам каждого канала и языкам. [English](README.md). Без API, хранения, отправки брифа, расчёта цены и обещаний сроков.

## Запуск

Node 20+, из папки пакета:

```sh
node cli.mjs examples/valid.ru.json json ru
node cli.mjs examples/valid.ru.json csv ru > versions.csv
node --test tests/*.test.mjs
```

Коды завершения: 0 — план готов; 1 — вход отклонён; 2 — ошибка файла/JSON/команды. При ошибке даже в режиме CSV выводится JSON: проверяйте код завершения. В успешном CSV предупреждения идут в stderr. Максимальный файл — 256 КиБ.

Браузер и Node используют один `planner.mjs` без импортов: `planCampaign(input, {language:'ru'})` возвращает `{valid,errors,warnings,versions,total}`. `versionsToCsv(result.versions)` создаёт CSV, `planToJson(result)` — полный JSON. В браузере модуль нужно отдавать по HTTP; до разбора JSON ограничьте размер 256 КиБ. Произвольные JS-геттеры/прокси не входят в контракт.

Вход: `durations` — целые секунды 1–3600; `channels` — объекты `{id,label?,aspectRatios}`; `locales` — языковые теги, например ru/en/en-US. Неизвестные поля отклоняются. До 100 длительностей, 100 каналов, 100 языков; до 20 форматов на канал. ID — строчная латиница, цифры и разделяющие дефисы, до 40 символов. Подпись — до 80 символов Unicode, без управляющих символов, угловых скобок и начальных префиксов формул.

Соотношения сторон — положительные целые числа 1–99 через двоеточие. Форматы задаёт пользователь **отдельно каждому каналу**: горизонтальный формат сайта не добавляется автоматически вертикальному социальному каналу. Это допущения пользователя, не подтверждённые требования платформ.

Дубликаты длительностей, языков после перевода в нижний регистр и одинаковых строк формата удаляются с предупреждениями. Повтор ID объединяет форматы только при одинаковой подписи; разные подписи дают ошибку. Без подписи используется ID. Строки 1:1 и 2:2 не объединяются математически.

Число версий = уникальные длительности × языки × сумма форматов по каналам. До **1000** включительно; превышение отклоняет весь план. Результат отсортирован по каналу, формату, языку и длительности. ID стабилен при перестановке входа; подпись не меняет ID. Языковые теги проверяются синтаксически, без реестра и без обещания наличия перевода.

CSV корректно экранирует кавычки и запятые; формулы и управляющие символы отклоняются и при прямом вызове экспорта. JSON сохраняет предупреждения. Схемы описывают структуру; объединение дубликатов и предел комбинаций проверяются модулем.
