# SHAR: таксономия производства и синтетические брифы · 1.0.0

Релиз dataset 1.0.0. Авторская таксономия и синтетические данные: [CC-BY-4.0](LICENSE-CC-BY-4.0). Код, JSON-схемы и документация: [MIT](LICENSE). [Границы лицензий и атрибуция](LICENSE-STATUS.md). [English / Dataset card](README.md).

Набор содержит 18 авторских терминов RU/EN и 8 синтетических брифов: четыре вымышленных сценария на двух языках. Он помогает строить интерфейсы подготовки брифа и проверять примеры. Это не ML-benchmark, исследование рынка, статистика клиентов или база цен.

Сценарии: многоразовая упаковка, канцелярские товары, общественная мастерская и выставочное пространство. Настоящих клиентов, контактных данных, материалов и измерений нет. Переводы не считаются независимыми наблюдениями.

Подготовлено 05.09.2026 с помощью AI для редакторской проверки владельцем SHAR. Основа понятий — публичная схема https://sharprod.com/schemas/agent-brief.schema.json и руководство https://sharprod.com/journal/video-production-brief.html. Это предлагаемая учебная классификация, не утверждение о согласии всей отрасли или завершённой экспертной проверке.

В JSONL сохранены ID, версия, происхождение authored/synthetic, метод создания, дата, ссылки на концептуальные источники и статус лицензии. Ссылки не доказывают существование вымышленных проектов. Измеренных записей и выгрузки бизнес-фактов нет. `examples.json` — браузерная проекция этих же данных, не новый dataset.

Из папки пакета:

```sh
python -m pip install -r requirements-test.txt
python tests/load_huggingface.py
node --test tests/dataset.test.mjs
```

Python-тест загружает JSONL через `datasets.load_dataset('json', ...)`, проверяет схемы и полное совпадение после Arrow с нормализацией распознанных дат обратно в строки ГГГГ-ММ-ДД. Он не публикует данные. Node-тест использует соседний пакет `../production-brief/` и проверяет валидность брифов, ссылки на термины и совпадение браузерной проекции. Для Python соседний пакет не нужен.

`train` — техническое имя раздела загрузчика, не обещание пригодности для обучения. Набор слишком мал и узок для оценки качества моделей. Структурно валидный бриф требует содержательной проверки, согласования прав и сроков. Бюджетные тексты — условные заполнители, не цены SHAR.
