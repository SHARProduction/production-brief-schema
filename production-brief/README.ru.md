# SHAR: проверка полноты брифа · 1.0.0

Релиз 1.0.0. [English](README.md). Код, документация и JSON-схемы: [MIT](LICENSE). Синтетические JSON-примеры: [CC-BY-4.0](LICENSE-CC-BY-4.0). [Границы лицензий и атрибуция](LICENSE-STATUS.md). Владелец разрешил публикацию в `Ares3333333/production-brief-schema`; доступность публикации проверяется отдельно.

Инструмент проверяет структуру брифа перед обсуждением видеопроизводства: обязательные поля, длины, массивы, дату и форматы. Он не оценивает идею, не подтверждает права, не рассчитывает цену и не отправляет заявку.

## Запуск

Node.js 20+, установка зависимостей не нужна. Из папки пакета:

```sh
node cli.mjs examples/valid.ru.json ru
node cli.mjs examples/invalid.json ru
node --test tests/*.test.mjs
```

Коды завершения: 0 — корректный бриф; 1 — ошибки проверки; 2 — ошибка файла, JSON или команды. Предел файла — 256 КиБ. Сообщение об ошибке чтения может содержать путь: не используйте личные данные в имени файла.

В браузере подключите `validator.mjs` вместе с `schema.mjs` как ES-модули. API: `validateBrief(value, {language: 'ru'})`, результат: `{valid, errors: [{path, code, message}]}`. `path` — JSON Pointer. Перед JSON.parse интерфейс должен ограничить размер ввода 256 КиБ. Передавайте разобранный JSON, а не произвольные JavaScript-объекты с геттерами.

## Поля и границы

Обязательны objective (цель), audience (аудитория), deliverables (результаты), channels (каналы), launchDate (дата), budgetContext (бюджетный контекст), rightsConstraints (ограничения прав). Необязательны references, locales, aspectRatios, notes. Неизвестные поля отклоняются. Существующая прошедшая дата допустима структурно: реалистичность сроков проверяет человек.

Понятия взяты из публичной схемы https://sharprod.com/schemas/agent-brief.schema.json и руководства https://sharprod.com/journal/video-production-brief.html. Отдельный профиль строже проверяет пустые строки, положительные пропорции и HTTP(S)-ссылки без логина/пароля. Это не схема отправки MCP. Ссылки не открываются; их доступность и публичность не подтверждаются.

`brief.schema.json` — JSON Schema 2020-12; `schema.mjs` — эквивалент для браузера, совпадение проверяется тестом. Стороннему валидатору потребуется проверка format; `x-no-credentials` — дополнительное правило нашего приложения. Модуль поддерживает только ключевые слова этого профиля.

Примеры синтетические: вымышленные задачи и даты, не клиентские проекты и не цены SHAR. Сети, аналитики, хранения и отправки нет. Подготовленный бриф можно обсудить через [контакты SHAR](https://sharprod.com/contact.html); переход и отправку выполняет пользователь. Существующий [калькулятор](https://sharprod.com/production-tools/video-cost-calculator/) остаётся отдельным инструментом.
